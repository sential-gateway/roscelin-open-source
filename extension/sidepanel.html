Connect Vikunja

Under Projects tick Read All and Read One; under Tasks tick Read All, Read One, Create and Update. Don't tick the bold group names (that selects everything, including Delete). Dictate your request

Optional English (US) dictation using your browser's on-device speech support. No cloud fallback. Roscelin does not record or save audio. Requires microphone permission and an available local language pack; this version does not install packs.

Microphone off. Dictation never submits or runs actions.

Browser inspection (experimental)

Inspect and highlight an open Vikunja task in the original app. Browser writes are disabled because its cached page data could overwrite newer task fields. Use the existing API-backed task controls for edits.

This is an inspection prototype, not an autonomous browsing agent or OS cursor. Original-page write support remains unfinished.
